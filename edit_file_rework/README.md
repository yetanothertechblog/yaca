# Edit File Rework Analysis

This directory contains analysis and scripts related to Claude API response format for tool calls, specifically focusing on how edit operations work.

## Files

### Data Files
- `anthropic_edit_response.json` - Raw streaming API response from Claude containing a tool call
- `final_diff.diff` - Final diff file generated from the API response
- `single_diff.diff` - Intermediate diff file during extraction process

### Analysis Scripts
- `convert_to_diff.py` - Initial attempt to convert streaming JSON to diff
- `extract_diff_content.py` - Improved script to extract content from streaming response
- `better_extract_diff.py` - More comprehensive extraction with multiple fallback methods
- `create_final_diff.py` - Script to create proper unified diff format
- `extract_tool_input.py` - Script to extract and reconstruct the complete tool input JSON

## Analysis Summary

### Key Findings
1. **API Response Format**: Claude uses Server-Sent Events (SSE) with `event:` and `data:` lines
2. **Tool Call Structure**: Tool calls are streamed as `input_json_delta` events that need to be concatenated
3. **Content Only**: The API only provides the new content to write, NOT the old content or line numbers
4. **Diff Generation**: The agent must read the existing file from disk and generate diffs using algorithms like LCS (Longest Common Subsequence)

### How It Works
1. Claude sends a `Write` tool call with `file_path` and `content` fields
2. The content is streamed as JSON chunks in `input_json_delta` events
3. The agent reads the existing file from disk
4. The agent compares old vs new content using LCS algorithm
5. The agent generates a unified diff with +/- markers
6. The agent applies the diff using context lines as anchor points

### Important Notes
- **Old content is NOT in the API response** - it comes from reading the file on disk
- **Line numbers are calculated**, not provided by the API
- **Diff format is generated by the agent**, not Claude
- **Context lines** in the diff serve as anchor points for change application
