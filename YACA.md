# YACA (Yet Another Coding Assistant) Configuration

## Project Context
This is a Go TUI application that provides an AI coding assistant with LSP support.

## Coding Guidelines
- Follow Go best practices and conventions
- Use proper error handling
- Write idiomatic Go code
- Add appropriate comments for complex logic
- Use the provided tool system for file operations

## Project Structure
- `tui/` - Terminal User Interface components
- `agent/` - AI agent and system prompt logic
- `config/` - Configuration constants and model definitions
- `permissions/` - Tool permission management
- `conversation/` - Conversation persistence

## Development Preferences
- Prefer simplicity over complexity
- Test thoroughly before making changes
- Keep dependencies minimal and well-maintained
